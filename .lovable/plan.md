# Cyber-Glitch Overdrive

## Goal
Transform the full Baycon homepage into the selected high-intensity cyber-glitch direction without changing its content, pricing, portfolio loading, contact form, or admin access.

## Build
- Recompose the opening screen with oversized layered BAYCON typography, broadcast overlays, animated grids, scan beams, status readouts, and sharper calls to action.
- Apply a consistent industrial broadcast language to every section: angular frames, numbered section markers, moving ticker strips, kinetic headings, animated borders, and staggered reveals.
- Intensify cards, portfolio frames, pricing, FAQ, contact form, and footer with distinct movement and interaction while preserving readability.
- Add reduced-motion behavior so the experience remains usable for visitors who disable animation.
- Keep the existing red, black, and white palette, CMS-driven work, current prices, contact storage, and navigation destinations unchanged.

## Validation
- Check the homepage at desktop and mobile sizes for legibility, overlap, working navigation, media display, and form access.
- Confirm the latest preview build has no errors.

## Technical details
- Implement the motion system with CSS animations and the existing React structure; no new runtime dependency is required.
- Keep all color and effect values in the site design tokens and global styles.
